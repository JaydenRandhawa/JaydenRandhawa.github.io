        Recurring task

        Repeat on

        Off: the next 7 days of tasks are added ahead of time. On: each task appears only on its own day, and if it isn't done by the end of the day it moves to the current day. Finishing one day's task never affects the next. Repeating stops when the weeks run out or this reminder is marked done.

        Sync & privacy

        Passphrase lock

        Encrypts your tasks (AES-256) on this device and in the cloud. The passphrase is never saved. If you forget it, encrypted data can't be recovered.

        The lock is on. You'll be asked for the passphrase each time you open the app.

        Cloud sync (Firebase Firestore)

        Use the same account ID and config on your laptop, phone and iPad. Changes merge per task, so edits from different devices don't overwrite each other.

        Firebase config loaded from firebase-config.js. You only need the account ID.

        How to set this up
        1. In the Firebase console, create a project and add a Firestore database.
        2. Open Project settings, add a Web app, and copy its firebaseConfig.
        3. Save it in firebase-config.js next to index.html (or paste it above if you have no such file).
        4. Pick a long account ID and use the same one on every device.
        5. In Firestore Rules, allow the paperTodo collection:
        rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /paperTodo/{accountId} {
      allow get, write: if true;
    }
    match /paperTodoCal/{token} {
      allow get, write: if true;
    }
  }
}

        These rules let anyone who knows a document's exact name read or write it, but nobody can list the collections. The account ID and the calendar token act as secrets, so keep them private, and turn on the passphrase lock so your list is encrypted.

        Calendar

        Tick "Show on my calendar feed" on the items you want, then subscribe once on your phone. Tasks appear as all-day events on their to-do and due dates. Reminders can be all-day or a time block. A task linked to a reminder stays off the calendar and the reminder shows instead. Completed items drop off.

        Set up the free Cloudflare Worker (one time)

        Calendar apps need a web address that serves an .ics file, and a static GitHub Pages site can't do that. A tiny free Cloudflare Worker reads the feed from Firestore and hands it to your calendar.

        1. Create a free account at dash.cloudflare.com.
        2. Open Workers & Pages, create a new Worker, and name it (for example todo-calendar).
        3. Open its code editor, replace everything with the code below, and deploy.
        4. Copy the address ending in .workers.dev into the Worker URL box above. You only do this once: it's saved with your account.
        5. Add the paperTodoCal block to your Firestore rules (see the setup steps in the cloud settings).
